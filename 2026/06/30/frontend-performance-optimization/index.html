前端性能优化实战

2026-06-30 performance ， frontend ， nextjs

性能优化不是玄学，而是一套可量化的工程实践。核心指标围绕 Web Vitals 展开。

核心指标

指标 含义 目标
LCP 最大内容绘制 < 2.5s
FID 首次输入延迟 < 100ms
CLS 累计布局偏移 < 0.1
INP 交互到下次绘制 < 200ms

优化策略

1. 减少 JavaScript 体积

提示

Next.js App Router 的 Server Components 默认不为客户端发送 JS——这是零成本优化。本博客的文章详情页就是纯 Server Component。

2. 图片优化

graph LR
  A[原始图片] --> B[WebP/AVIF 转换]
  B --> C[多尺寸生成]
  C --> D[懒加载]
  D --> E[CDN 分发]

3. 字体优化

信息

使用 font-display: swap 和 WOFF2 格式，能将字体加载对 LCP 的影响降到最低。
