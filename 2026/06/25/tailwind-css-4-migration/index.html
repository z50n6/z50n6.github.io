Tailwind CSS 4 迁移指南

2026-06-25 frontend ， tailwind ， css

Tailwind CSS 4 是一次重大更新，引入了 CSS-first 配置和 OKLCH 色彩空间。本文记录实际迁移中的变化。

配置方式改变

v3 的 tailwind.config.ts 变成了 v4 的 CSS 原生配置：

重要

v4 不再需要 tailwind.config.ts 文件，所有配置直接写在 CSS 中。这意味着你可以在组件级别定义主题变量。

成功

zBlog 已迁移到 Tailwind CSS 4。代码块、导航栏、筛选区都使用了 OKLCH 色彩和容器查询。

迁移检查清单

  • 移除 tailwind.config.ts
  • 迁移到 @theme 指令
  • 颜色从 hex 转为 OKLCH
  • @apply 改为 CSS 原生层叠
  • 更新 postcss.config.mjs
  • 测试所有暗色模式组件

警告

部分 v3 插件尚未兼容 v4。迁移前检查你依赖的插件是否有 v4 版本。
