建议把 manifest.json 中的 id 改成你的插件唯一标识，否则无法发布到社区插件市场。

核心 API：addCommand

插件生命周期

sequenceDiagram
  participant User
  participant Obsidian
  participant Plugin
  User->>Obsidian: 启动应用
  Obsidian->>Plugin: onload()
  Plugin-->>Obsidian: 注册命令/事件
  User->>Plugin: 触发命令
  Plugin->>Obsidian: 操作文件/界面
  User->>Obsidian: 关闭应用
  Obsidian->>Plugin: onunload()
  Plugin-->>Obsidian: 清理资源

小心

onunload() 中务必移除所有事件监听器和定时器，否则会导致内存泄漏。
