任意文件上传

2026-06-28 WEB渗透 ， 基础漏洞

一、概述

1.1 是什么

文件上传是 Web 应用的必备功能——头像上传、附件分享等。如果服务器配置不当或没有充分过滤，用户可以上传任意文件（恶意脚本、exe 程序等），这就是任意文件上传漏洞。通过它获取的网站后门叫 WebShell。

1.2 漏洞成因

  • 服务器开启了 PUT 方法
  • Web 开放了上传功能但没充分限制
  • 开发部署时未考虑：代码特性、组件漏洞、Web 容器漏洞、系统特性

七、防御

代码层面：

  • 白名单策略，严格限制上传后缀名
  • 文件重命名，尽量少从客户端取值
  • 文件内容头部检测 + 二次渲染过滤图片马
  • 避免文件包含漏洞
  • 严格处理路径，防御 %00 截断
  • 检测 Token 防 CSRF 重放

Web 容器 / 系统层面：

  • 及时更新 Web 容器，禁用 PUT 方法
  • 避开空格、.、::$DATA 等系统特性
  • 执行权限与写权限分离，站库分离

业务层面：

  • 强口令策略，避免攻击者登录后台
  • 避免 Web 用户修改上传白名单
