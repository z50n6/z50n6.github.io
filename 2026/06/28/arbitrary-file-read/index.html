任意文件读取 / 下载

2026-06-28 WEB渗透 ， 基础漏洞

一、概述

1.1 是什么

一些网站提供文件查看或下载功能。如果对用户指定的文件没有限制或限制可被绕过，就可以读取任意文件——源代码、配置文件、系统敏感文件。

任意文件读取和下载本质无区别：信息都是从服务端流向浏览器，差异只在表现形态（页面展示 vs 触发下载行为）。

1.2 漏洞成因

四个条件齐了就出事：

  1. 存在读取文件的功能（函数）
  2. 读取文件的路径客户端可控
  3. 路径校验缺失或校验不严被绕过
  4. 输出了文件内容

1.3 危害

  • 读取源代码、配置文件、系统敏感文件
  • 代码审计：从源码中挖更多漏洞（SQL 注入、未授权接口等）
  • 读取日志获取用户行为和请求记录
  • 配合其他漏洞构成完整攻击链
