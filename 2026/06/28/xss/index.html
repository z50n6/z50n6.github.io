XSS 跨站脚本攻击

2026-06-28 WEB渗透 ， 基础漏洞

一、概述

1.1 是什么

跨站脚本攻击（Cross-Site Scripting），由于与 CSS 重名，更名为 XSS。本质是客户端代码注入——攻击者在合法网站中注入恶意脚本，用户访问被注入的页面时，浏览器解析并执行这段 JS。

XSS 用 JavaScript 完成攻击。JS 可以灵活操纵 HTML、CSS、浏览器，给了 XSS 极大的攻击面。

1.2 攻击原理

三个角色参与：

服务器 → 攻击者 → 客户端浏览器用户

sequenceDiagram
    participant A as 攻击者
    participant S as 服务器
    participant V as 受害者浏览器

    A->>S: ① 提交恶意脚本（留言/评论/参数注入）
    Note over S: ② 恶意脚本被存入数据库
或嵌入响应页面
    V->>S: ③ 受害者访问含脚本的页面
    S-->>V: ④ 返回含恶意脚本的页面
    Note over V: ⑤ 浏览器解析并执行脚本
    V-->>A: ⑥ Cookie / 敏感数据被外带
    Note over A: ⑦ 攻击者劫持会话 / 钓鱼 / 蠕虫

核心：攻击者写，受害者读，浏览器执行——攻击者全程不需要直接接触受害者。

搜索框、登录框、留言板、聊天室——一切收集用户输入的地方都可能被注入 XSS 代码。XSS 需要等待受害者访问被注入的页面，比较被动，所以又叫”盲打”。

1.3 漏洞危害

  • 网络钓鱼，获取各类用户账号
  • 窃取 Cookie，获取隐私信息或冒充受害者操作
  • 劫持会话，执行任意操作（转账、发帖等）
  • 强制弹出广告、刷流量
  • 网页挂马
  • 篡改页面、删除文章
  • 大量客户端攻击（如 DDoS）
  • 获取客户端信息（浏览历史、真实 IP、开放端口）
  • 控制受害者机器向其他网站发起攻击
  • 结合 CSRF 扩大危害
  • 提升权限，进一步渗透
  • 传播跨站脚本蠕虫

二、漏洞分类

2.1 反射型 XSS

flowchart LR
    A[攻击者] -->|"① 构造恶意链接"| V[受害者]
    V -->|"② 点击(带payload)"| S[服务器]
    S -->|"③ 响应中直接回显payload"| V
    V -->|"④ 浏览器执行脚本"| A

非持久性、参数型。XSS 代码出现在 URL 参数中，每次触发都需要受害者点击带 payload 的链接。

容易被发现，利用难度高，很多漏洞平台不收。

2.2 存储型 XSS

flowchart LR
    A[攻击者] -->|"① 提交恶意脚本"| S[服务器]
    S -->|"② 存入数据库"| DB[(数据库)]
    V[受害者] -->|"③ 正常访问页面"| S
    S -->|"④ 从DB读取并返回含脚本页面"| V
    V -->|"⑤ 浏览器执行脚本"| A

持久性——XSS 代码写进数据库或文件。通常发生在留言板、评论区。用户提交恶意内容 → 存入数据库 → 任何人访问该页面即触发。

危害面广，漏洞平台通常收此类。

2.3 DOM 型 XSS

flowchart LR
    A[攻击者] -->|"① 构造恶意链接(#锚点)"| V[受害者]
    V -->|"② 点击链接"| S[服务器]
    S -->|"③ 返回正常页面
(不含恶意代码)"| V
    V -->|"④ 前端JS读取#后面内容并操作DOM"| V
    V -->|"⑤ 脚本在浏览器端执行"| A

通过修改浏览器本地 DOM 树触发，payload 不上传到服务器。常用 # 锚点传参，参数不提交到服务端，导致 DOM 型 XSS 难以检测。

2.4 mXSS（突变型）

Payload 提交时无害，但由于反编码、解析差异等原因发生”变异”，最终产生 XSS。典型场景：富文本过滤器中 innerHTML 赋值导致 payload 变形。

2.5 UXSS（通用型）

Universal XSS——利用浏览器或浏览器扩展自身的漏洞来制造 XSS 条件。可以理解为绕过同源策略，不限于单个网站。

2.6 Flash XSS

SWF 文件中与 JS 交互的两个关键点：

  • getURL / navigateToURL — 访问跳转
  • ExternalInterface.call — 调用 JS 函数

白盒：反编译 swf → 搜 ExternalInterface.call → 看是否有可控参数传入。
黑盒：扫描路径 → 找 .swf 文件 → 下载反编译看源码。
