XML 外部实体注入（XXE）

2026-06-28 WEB渗透 ， 基础漏洞

一、概述

XXE（XML External Entity Injection），XML 外部实体注入。漏洞出现是因为应用程序解析 XML 输入时没有禁用外部实体加载，攻击者可以加载恶意外部资源。

核心危害：

  • 文件读取（最常见、PoC 最快）
  • SSRF（内网探测、云元数据窃取）
  • 命令执行（需要 expect 扩展，很少碰到）
  • 拒绝服务（Billion Laughs 实体展开）

根本原因一句话：网站接受 XML 数据，解析器开启了外部实体引用，且没有过滤。

九、防御

核心：禁用外部实体 + 禁用 DTD 解析。靠关键词过滤 <!DOCTYPE / SYSTEM 不靠谱。

渗透测试的底线：XXE 先 DNSLog 证明存在，再 OOB 证明危害。PoC 选最简单的——一个 DNSLog 请求就能定性，比复杂的 DTD 链实用得多。
