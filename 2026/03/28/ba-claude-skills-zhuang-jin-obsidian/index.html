把claude-skills装进obsidian

核心主题

本视频介绍了如何将 Claude 技能（claude-skills）集成到 Obsidian 中，通过 AI 增强 Obsidian 的功能，提升笔记管理和知识工作的效率。

技术资源

主要插件资源

1. Obsidian Skills（文本分析类）

  • 项目地址：kepano/obsidian-skills
  • 功能：提供文本分析、摘要生成、代码解释等多种 AI 技能
  • 特点：功能全面，与 Obsidian 深度集成

2. Axton Obsidian Visual Skills（可视化类）

  • 项目地址：axtonliu/axton-obsidian-visual-skills
  • 功能：专注于可视化功能，支持图表、思维导图生成
  • 特点：效果出色，学习成本低

3. Claudian（Claude 集成插件）

  • 项目地址：YishenTu/claudian
  • 功能：提供 Claude API 集成和 Claude 技能管理
  • 特点：支持国内网络环境的 Claude API 访问

安装与配置

插件安装

下载 Claudian 项目 release 中的 main.js\styles.css\manifest.json 至 .obsidian/plugins/claudian/ 下，然后「启用」插件

API 配置

需要在插件设置中配置以下环境变量：

配置说明：

  • ANTHROPIC_API_KEY：需要从字节跳动火山引擎获取的 API 密钥
  • ANTHROPIC_BASE_URL：火山引擎提供的 Claude API 接口地址
  • ANTHROPIC_DEFAULT_OPUS_MODEL：默认使用的 Claude 模型（豆包种子代码预览版）

功能特点

Obsidian Skills 功能

  • 智能笔记摘要生成
  • 内容自动分类与标签建议
  • 文本翻译与语言转换
  • 代码语法高亮与解释
  • 自定义技能开发支持

Axton Obsidian Visual Skills 功能

  • 文本转思维导图
  • 数据可视化（图表生成）
  • 笔记内容关系图谱分析
  • 可视化摘要与演示
  • 支持多种图表类型（柱状图、折线图、饼图等）
