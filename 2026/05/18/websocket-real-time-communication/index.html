WebSocket 实时通信入门

2026-05-18 frontend ， websocket ， nodejs

HTTP 是请求-响应模型，服务器无法主动推送数据。WebSocket 解决了这个问题。

HTTP 轮询 vs WebSocket

sequenceDiagram
  participant C as 客户端
  participant S as 服务器

  rect rgb(255,240,240)
  Note over C,S: HTTP 轮询（浪费）
  C->>S: 有新消息吗？（第1次）
  S-->>C: 没有
  C->>S: 有新消息吗？（第2次）
  S-->>C: 没有
  C->>S: 有新消息吗？（第3次）
  S-->>C: 有！
  end

  rect rgb(240,255,240)
  Note over C,S: WebSocket（高效）
  C->>S: 建立连接
  Note over C,S: 连接保持打开
  S-->>C: 有消息！（主动推送）
  end

生产环境应使用 wss://（WebSocket over TLS），并在 Nginx 中配置 WebSocket 代理。

适用场景

场景 推荐方案
聊天应用 WebSocket
实时通知 WebSocket / SSE
股票行情 WebSocket
文件上传进度 WebSocket
简单轮询 SSE (Server-Sent Events)

问题

SSE 是单向的（服务器→客户端），比 WebSocket 更简单且天然支持自动重连。如果你的场景不需要双向通信，优先考虑 SSE。
