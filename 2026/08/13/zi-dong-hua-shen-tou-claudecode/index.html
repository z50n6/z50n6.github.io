一、环境准备

  • 系统：Kali Linux（工具链齐全；Windows 缺工具，效果打折）。
  • 安装 Claude Code：curl -fsSL https://claude.ai/install.sh | bash，大陆网络需要全局代理。
  • 打 ClawGod 补丁解除限制；用 cc-switch 配置模型 API。
  • 模型选限制少、听话的：智谱 GLM、MiniMax 效果好，DeepSeek Pro 性价比高；ChatGPT 拉黑。

  • 更多清单：ClaudeCode 好用 Skill 以及插件工具

四、配置 MCP

MCP 让 Claude Code 直接调用外部工具（抓包、扫描器、浏览器、验证平台）。项目级配置放工作目录下的 .mcp.json，启动时自动读取；会话里用 /mcp 查看连接状态，也可以 claude mcp add 单独添加。

五、注意

  • 一个会话只打一个目标，别一次给一堆；换目标时重开会话。
  • 无害 PoC 让它直接打；删数据、DoS、改生产环境这类破坏性操作，它会停下确认。
  • 建议独立 Kali 虚拟机，别和日常环境混。
  • 目标给得越小越集中，效果越好。
