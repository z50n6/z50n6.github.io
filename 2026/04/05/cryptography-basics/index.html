密码学基础概念梳理

2026-04-05 安全 ， crypto

密码学是信息安全的基石。本文用尽可能直白的语言解释开发者日常接触的核心概念。

哈希（Hash）

把任意长度的数据映射为固定长度的指纹：

特性：单向、抗碰撞、雪崩效应。

重要

密码存储永远用 bcrypt/scrypt/argon2，不要用 SHA-256 直接哈希密码——它太快了，暴力破解成本太低。

示例

TLS 握手用非对称加密交换密钥，后续数据传输用对称加密——兼顾安全与性能。

JWT 与签名

警告

JWT 的 payload 只是 Base64 编码，不是加密！不要把敏感信息放进 payload，除非你用了 JWE。

核心原则

引用

“Don’t roll your own crypto.”

除非你是密码学专家，否则永远使用经过审计的标准库。

  • 哈希密码：bcrypt / argon2
  • 加密数据：libsodium / Web Crypto API
  • 签名/验证：jose / OpenSSL
